## 1. What SaveCents is

AI-powered behavioral personal finance app for Filipinos. Cents (the AI coach) intercepts purchases: users log expenses by chatting naturally (English/Tagalog/Taglish), scan items and receipts with an in-app camera, ask "can I afford this?", and get real trade-off math ("this delays your Hong Kong Trip by 3 weeks"). Zero-based budgeting across PH wallets/banks (GCash, Maya, BPI…), goals with trajectory projections.

**Design direction (LOCKED):** user-friendly, user-focused, NOT techy. Green/White/Sage light theme default (deep-green dark theme available; light is enforced as default via persist migration v3). Matte liquid glassmorphism in the app; the AUTH screens are deliberately SIMPLE solid cards (owner call, v17). Brand yellow `t.centsYellow = #FFDE59` (sampled from the logo) marks everything Cents. **Hard content rules: no emojis, no em dashes, no feature disclaimers anywhere in user-facing copy. Every visible button must do something real.**

React Native + Expo **SDK 54** (do NOT upgrade until the dev build lands). TypeScript, expo-router, zustand (persist **version 4**).

1. **Worker:** `getAccessToken()` mints a Google access token from the service account (secret `FIREBASE_SA_JSON` = the whole downloaded JSON; RS256 JWT signed with WebCrypto, cached ~1h). `/reset-request` calls identitytoolkit accounts:sendOobCode (PASSWORD_RESET, returnOobLink) with admin auth, extracts the oobCode, stores it in KV alongside the SHA-256 of a fresh 6-digit code (10-min TTL, 5 tries, 3 sends/hour), and emails the code with reset-specific copy ("Reset your password") on the same branded template. Unknown emails return a generic ok - NO account enumeration, no email. `/reset-verify` releases the oobCode on a correct code and burns the record. Missing FIREBASE_SA_JSON → 501.
2. **App:** otp.ts gained `requestResetOtp` (501 → OtpUnavailableError) and `verifyResetOtp` (returns the oobCode); auth.ts gained `completePasswordReset` (confirmPasswordReset wrapper). auth.tsx "Forgot password" now: requests the code → opens a themed Modal (code entry with big spaced digits → new password + repeat) → verify releases the oobCode → completePasswordReset → "Password updated. Sign in with your new password." The classic Firebase link email remains the automatic fallback whenever the Worker/service account isn't configured - fresh clones lose nothing.
3. **worker/README.md** gained the 5-minute service-account section (Console → Service accounts → Generate new private key → `wrangler secret put FIREBASE_SA_JSON` → deploy).
4. Security notes: the app never sees the oobCode until the emailed code checks out; the oobCode is Firebase-minted and single-use; codes are stored hashed; the service-account JSON lives ONLY as a Worker secret (never in the repo, never in the app).
5. Verified: `npx tsc --noEmit` clean, `npx expo export --platform ios` bundles.
